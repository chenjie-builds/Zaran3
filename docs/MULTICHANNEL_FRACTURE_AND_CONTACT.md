## 一、为什么补这四项

| 缺口 | 症状 | 本轮的实现 |
|---|---|---|
| A4 切向独立断裂 | 键只有"法向能量/应变"一条失效通道，破坏一旦发生就是同时、全域、不可逆 | `Et ≥ UtIII` ⇒ 切向先断并**折减法向阈值**（LSM `GBratio`） |
| A5 压剪 | 孔洞/裂隙壁面的错动在压缩侧，而压缩侧只有"压溃"一条通道 | 压缩侧 `Et ≥ UtIII` 单独成一条通道（`breakmod=2`） |
| C1 滚动阻力矩 | 碎块之间只剩光滑球-球接触 ⇒ 碎块堆像干砂一样摊平 | `M_r = −μ_r·R*·|F_n|·ω̂_rel` |
| C3 切向接触阻尼 | 粘滞-滑移转换时完全没有切向耗能，碎块间切向振荡不衰减 | `c_t = λ·c_n` |

**四项全部默认关闭**（`α = 0`、`μ_r = 0`、`λ = 0`），
所以 19 项历史回归 + 新增 3 项合计 **22/22 逐位不变**。

## 二、A4/A5：键的多通道失效

### 2.1 LSM 的四条通道与本工程的对应

| LSM `breakmod` | 判据 | 本工程 |
|---|---|---|
| 1 拉伸混合 | `En + Et ≥ UnIII` | ✅ 本轮补齐（内聚分支内） |
| 2 压剪 | `rn ≤ r0` 且 `Et ≥ UtIII` | ✅ 本轮补齐 |
| 3 压缩压溃 | `rn < rnmax·0.6` | 已有（`bond_compression_strength_ratio` / `bond_break_strain_compression`） |
| 4 切向弹簧独立断裂 | `Et ≥ UtIII` ⇒ `tangent = .false.` + 折减 `GBratio` | ✅ 本轮补齐 |

`En = 法向包络面积`、`Et = ½·k_t·|δ_t|²`、`UnIII = bond.fracture_energy`、
`UtIII = α·UnIII`（新参数 `dem.bond_shear_energy_ratio`，α ∈ (0,1)）。

### 2.2 阈值折减的能量守恒写法（**踩过一次坑，务必按这个口径**）

LSM 的折减规则是

```
GBratio_new = (UnIII − UtIII) · GBratio_old / UnIII        （只降能量阈值）
```

而 **`rnmax`（失效分离度 δ_f）是材料常数、LSM 全程不改动**，判据用的是
`UnIII·GBratio`。本工程据此引入 `DEMBond::cohesive_budget_scale`（初值 1，
切向独立断裂时乘 `1 − α`），**法向能量预算** = `fracture_energy · s² · sas · budget_scale`：

```
失效判据：   area_env(e_drive) + Et ≥ 预算
失效记账：   dissipated_fracture = min(吸收的包络面积, 预算)
```

于是"造切向新表面"与"造法向新表面"共享同一份材料断裂能，能量预算耗尽即断。

> ⚠️ **不要按面积反解 δ_f**。第一版就是那么写的（`δ_f_eff = 2·(UnIII−UtIII)/F_p`），
> 结果在"法向通道**已经吸收了部分包络功之后**才发生切向断裂"时，
> 新包络把那段已吸收的功从账上抹掉 —— 实测**丢 0.0103 J**（相对 1.3e-5 的能量残差），
> 而且这个损耗会随着算例里切向断裂事件的数量累积。改成只折减阈值后，
> 单键算例的能量残差回到 **7.3e-7**（= 改造前默认路径的本底水平）。

### 2.3 记账口径（这是账本能闭合的关键）

| 项 | 记入 |
|---|---|
| 法向包络面积 `area_env(e_drive)` | `dissipated_fracture_energy`（不超预算） |
| 切向弹簧独立断裂时的储能 `Et` | `dissipated_shear_energy`（新字段） |
| 拉伸混合触发时的 `Et` | 同上（`dissipated_shear_energy += Et`） |
| 键断开瞬间残留的可逆储能 | 全部并入上面两项（`elastic_energy = 0`） |

`EnergyBudget.bond_fracture` = 两者之和（新字段 `bond_shear_fracture` 单列切向部分）。

可逐位验证的恒等式：设某一步里法向包络面积增量为 `ΔE_n`、切向弹簧储能增量为 `ΔE_t`，
则该步键吸收的能量恰为 `ΔE_n + ΔE_t`，而记账侧的变化也恰为 `ΔE_n + ΔE_t`
（推导见 `DEMBond.h` 注释）。单键算例实测残差 7.3e-7。

### 2.4 与法向损伤的关系（一处刻意的物理选择）

历史口径里切向力按 `(1−d)·sas` 折减（d = 法向损伤）。启用切向独立通道后，
切向弹簧**不再随法向损伤折减**（`tangential_factor = 1`），因为 LSM 的 `En` / `Et`
本就是两条独立通道、各有各的阈值。切向一旦独立断裂则彻底退出（因子归 0）。
默认关闭时 `fracture_energy_shear = 0` ⇒ 走历史口径，**逐位不变**。

### 2.5 切向断裂后不再累积 `δ_t`

`bond.shear_broken` 置位后，`δ_t` 每步清零。否则切向位移会重新增长，
让后面所有"切向储能"的口径（判据与记账）都虚高——这是一个静默错误。

## 三、C1：滚动阻力矩

```cpp
M_r = −μ_r · R* · |F_n| · ω̂_rel      （力偶，A 收 M_r、B 收 −M_r）
```

- `μ_r` 有**长度量纲**（`dem.rolling_friction`，量级 ~ 0.01–0.1·r），不是无量纲摩擦系数；
- **过冲截断**：`|M_r| ≤ I_eff·|ω_rel|/dt`。没有这一步，力矩会在静止接触上把
  `ω_rel` 推过零并反向，产生高频抖动（永远收敛不到"不滚"）；
- 耗散功率 `|M_r|·|ω_rel|` 恒 ≥ 0，计入 `DEMContact::dissipation` → 机械生热；
- particle-particle 与 particle-wall 两条路径都施加；墙面接触的耗散全给粒子。

---

## 四、C3：切向接触阻尼

```cpp
c_t = λ · c_n            （dem.tangential_damping_scale，λ ≤ 0 = 关闭）
F_t = −k_t·δ_t − c_t·v_t
```

- 与法向同一套恢复系数标定（`c_n = 2β√(m_eff·k_n)`，`β = −ln e/√(π²+ln²e)`）；
  按同恢复系数标定的理论比值是 `sqrt(k_t/k_n)`（线性模型 ≈ 0.707），λ 可自由给。
- **切向阻尼力与切向弹簧力合并后统一受库仑上限约束**，所以截断后重置的是
  "弹簧位移"而不是总力：`δ_t = −(F_t + c_t·v_t)/k_t`（λ = 0 时退化为 `−F_t/k_t`）。
- 耗散 `c_t·|v_t|²·dt` 计入 `contact.dissipation`。

## 五、新增参数与输出

| 参数 | 默认 | 含义 |
|---|---|---|
| `dem.bond_shear_energy_ratio` | `0` | α = UtIII/UnIII，∈ (0,1)；≤0 关闭切向通道 |
| `dem.rolling_friction` | `0` | μ_r（长度量纲）；≤0 关闭 |
| `dem.tangential_damping_scale` | `0` | λ = c_t/c_n；≤0 关闭 |

校验：`α ≥ 1` 报错（切向单独就能吃掉全部断裂能 ⇒ 折减无意义）；
`α > 0` 但 `bond_cohesive_enabled = false` 报错（UtIII 相对内聚断裂能定义）；
`α > 0` 但没有任何键有正 `fracture_energy` 时告警（静默失效是最难查的一类错误）。

输出新增列：

| 文件 | 新列 |
|---|---|
| `backup/iter=*/bonds.dat` | `shear_broken`、`dissipated_shear_energy`、`break_mode`、`tangential_displacement`、`cohesive_budget_scale` |
| `result/bonds_<iter>.dat`（Tecplot） | `shear_broken`、`shear_energy_loss`、`break_mode`、`tangential_displacement`、`cohesive_budget_scale` |
| VTP CellData（受 `output.bond_details`） | `bond_shear_broken`、`bond_break_mode` |

`break_mode`：0 = 未失效，1 = 拉伸混合，2 = 压剪，3 = 压缩压溃，4 = 切向独立断裂。
**用它在 Tecplot 里着色，可以直接分辨"被拉开的 / 被剪坏的 / 被压碎的"区域。**

## 六、验证

### 6.1 `tests/dem_bond_shear_test`（25 项断言）

两条键：L0 = 1 m、kn = 1000、kt = 400、γ = 1 J/m²、ε_p = 0.01、α = 0.25。

```
A_bond = 1/√3                  = 0.5773502691896258 m²
UnIII  = 0.5773502691896258 J      UtIII  = 0.14433756729740643 J
δ_p    = 0.01 m                    F_p    = 10 N
δ_f    = 0.11547005383792515 m     ← 材料常数，全程不变
预算    = UnIII·(1−α) = 0.43301270189221930 J   ← 切向断裂后法向通道的余额
```

| 组 | 检查 | 实测 |
|---|---|---|
| A | 输出 δ_p / δ_f / fracture_energy 与解析值 | 1e-9 相对 |
| B | 切向断裂耗散 ≥ UtIII 且 < 一步上界（**是"跨越"而不是提前断**） | 0.144592 vs 0.144338 |
| B | 断裂帧 `break_mode = 4`、δ_t 归零、`budget_scale = 1−α` 精确 | 1e-12 |
| B | **δ_f 保持材料常数不变**（LSM 的 rnmax 从不改动） | 1e-9 相对 |
| C | 法向断裂耗散 = UnIII·(1−α) | 0.433013（1e-9） |
| C | **断裂帧 En ≥ 预算、上一帧 En < 预算**（确由"预算耗尽"触发） | 0.433270 / 0.432729 |
| C | 断裂伸长 0.0603 ≪ δ_f = 0.1155（是预算截断，不是分离度到顶） | ✓ |
| D | **拉伸混合**（键 2，切向未断）在 `extension = 0.0999 < δ_f = 0.1155` 处断裂 | En+Et 判据 |
| D | 法向耗散 = 实际包络面积；切向耗散 = 断裂时切向储能 | 1e-9 |
| E | 能量账本逐帧闭合（含转动动能） | **7.3e-7** |

**关键设计**：质量取 **5000 kg**。键的切向力会产生力偶（`arm = ½L·n`），
转动一旦主导就会污染"纯切向"的解析轨迹；转动耦合量级
`Δv_t/v_t = 5·k_t·t²/(2m)` 随质量反比下降，m = 5000 时实测 < 1e-3。

### 6.2 `tests/dem_rolling_test`（11 项断言）

小球（r = 1 mm）自转着放在**规定运动**的大球（R = 1 m）上，重力平衡 ⇒ `|F_n| = m·g` 恒定；
μ = 0 ⇒ 切向接触力恒为 0 ⇒ 小球不被推动；e = 1.0 ⇒ `c_n = 0` ⇒ 精确静止。
唯一让 ω 变化的就是滚动阻力矩。

| 检查 | 实测 |
|---|---|
| `|M_r|` = μ_r·R*·m·g（直接读输出 `torque_z`） | 相对偏差 **5.7e-10** |
| ω(t) 线性斜率 = `−μ_r·R*·g/(0.4·r²)` | **5.7e-10** |
| 停止时间 = ω0/|slope| | 4.5e-3 |
| 归零后**精确为 0**、全程不反向（过冲截断） | 0.000e+00 |
| **对照组**：悬空的同款小球 ω 全程严格不变 | max\|Δω\| = 0 |
| 位置不动（μ = 0 ⇒ 无切向力） | max\|Δy\| = 2.2e-16 m |

对照组是必要的：没有它，"ω 衰减"可能是数值耗散而不是滚动阻力。

### 6.3 `tests/dem_tangential_damping_test`（9 项断言）

同样的"小球 + 规定运动大球"构型，但给小球一个纯切向初速度 vx = 0.5 m/s，
且 μ = 1e6（库仑上限永不触发）⇒ **唯一的切向耗散就是 c_t**；`specific_heat = 1.0`
让温升可测。

| 检查 | 实测 |
|---|---|
| 从输出重建 v_n / v_t，按同一条离散式积分出 `Q_pred = Σ(c_n v_n² + c_t|v_t|²)dt` | — |
| 从温升读 `Q_meas = Σ m·c_p·ΔT` | — |
| **`Q_meas ≡ Q_pred`**（c_t 在预测式里显式出现 ⇒ 切向阻尼若未生效会差一大截） | 1.36% |
| 切向项占总耗散 | **100%** |
| `ΔKE ≡ Q_meas`（独立复核） | 0.78% |
| 末态落进**滚动不动点**（v_t 衰减 1e8 倍，但 vx 与 r·ω_z 等大反向、都不为零） | ✓ |

⚠ **两个坑**（都踩过）：
1. **第 0 帧必须一起积分**。它是初始状态、接触已建立（初始重叠量正是重力平衡的 δ0），
   第一步的耗散正是用这一帧的 v_n/v_t 算的；漏掉它 `Q_pred` 少 **18%**
   （切向振子在最陡的一段）。
2. 剩下的 1.3% 是**求积格式差**不是模型差：代码在每一步做左端点求和（步长 dt），
   校验脚本是逐帧梯形积分（帧距 5·dt），差值正好是 `½·dt·(f(0) − f(N))` 量级。

**三点读法（都直接对应最初的两个抱怨）**：
1. **裂纹真正连通了**：最大裂纹带 220 → 1086（×4.9）。旧模型只有一条孤立细带，
   新模型是贯通的裂纹网络 —— 这是"没有裂纹扩展"的直接反证。
2. **径向梯度从"平台+回升"变成"单调外减"**：旧模型在第 1–4 环之间是
   14.3 → 5.1 → 7.1 → **10.0**（中段又起了第二波弥散损伤）；
   新模型 69.7 → 52.6 → 30.3 → 15.2 → 11.3 → …单调衰减 ⇒ 标准的外扩裂纹形态。
3. **碎得"有结构"而不是粉化**：断键率翻倍（多切出更多断裂面），但最大完整碎块
   **反而略大**（30.9% → 33.3% 质量），同时碎块数 97 → 156、孤立单粒子 ×1.63
   ⇒ "几大块 + 更多碎屑"，正是 `CAVITY_GAS_BURST_GAPS.md` 里要的形态。

（同一算例在 t = 1e-5 s 的中途快照差异更剧烈：碎块 2 → 21、最大块质量占比
99.98% → 51.3%、最大裂纹带 95 → 682，见 `_demtest/hmx_compare_t1e-5.txt`。）
