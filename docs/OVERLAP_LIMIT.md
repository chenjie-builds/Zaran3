# 接触重叠限制：不允许两个粒子重叠过近

> 用途：在**逐步接触检测**中给接触对加一道下限保护——当两个粒子靠得过近时，
> 先按（准）弹性碰撞改写它们的法向速度、并（可选）非物理放大法向排斥力，
> 使接触法向不会翻转、粒子不会被"抛"出加载边界。
> 参考实现：LSM `code_utf8/force_between_discrete_lattices.f90` 与
> `linear_elastic_spring_mod.f90`（对应 LSM 的 `rn_limit` / `rn_rebound`）。

- 开关参数：`dem.contact_rebound_ratio`（默认 `0.5`）、`dem.contact_stiffen_ratio`（默认 `0.0`）
- 代码位置：
  - `inc/Zone/DEM/DEMSolverParam.h` / `src/Zone/DEM/DEMSolverParam.cpp`（参数）
  - `src/Zone/DEM/DEMSolver.cpp` → `DEMSolver::ApplyContactRebound()`（刚性回弹）
  - `src/Zone/DEM/DEMSolver.cpp` → `DEMSolver::AmplifyDeepOverlapForce()`（排斥力放大）
  - 调用点：`DEMSolver::CalcContactForce()`

---

## 1. 为什么需要这道保护

以巴西圆盘算例为例，加载边界由两排 **kinematic（规定运动）的离散球**组成。
接触刚度由粒子尺寸决定：`k_n = 2·E*·R*`；而试件内部的键合刚度可以高出它一个量级
（实测 `bonds.csv` 的 `kn = 2e4 N/m`，接触仅约 `1.9e3 N/m`）。于是压板行程里有相当一部分
被"吃"成接触重叠，`dist/(r_a+r_b)` 持续下降：

| iter | `min dist/(r_a+r_b)` | 深重叠对数 (`dist<0.5·d0`) |
|---|---|---|
| 0 | 1.035（尚未接触） | 0 |
| 50000 | 0.676 | 0 |
| 100000 | 0.329 | 20 |
| 150000 | 0.543 | 14 |
| 195000 | **0.209** | **54** |

一旦**压板球心越过样品粒子中心**，球-球法向 `(p_b−p_a)/|…|` 翻转，接触力由"压入"变成
"抛出"，粒子被弹到压板外侧——这就是观察到的"穿透"。因此需要在接近度下降到危险区之前
把两者截住。

## 2. LSM 的参考设置

LSM 在 `initializers.f90` 中定义（`r0` 为平衡格距）：

```fortran
rn_limit   = 0.6*r0      ! 过度压缩：非物理放大排斥力
rn_rebound = 0.5*r0      ! 深压缩：强制刚性回弹
```

`force_between_discrete_lattices.f90`（**离散体之间**的相互作用，正是 DEM 无键接触的对应物）
两者都在启用：

```fortran
!当rn<rn_limit时，将法向排斥作用非物理地放大
if(rn<rn_limit) then
    fn=((rn_limit/rn)**20)*fn
end if
!当rn<rn_rebound时，将相互靠近的格点刚性回弹
if(rn<rn_rebound) then
    ...
    if(vin<vjn) then                       ! 仍在相向运动
        a=massi-massj;  b=massi+massj
        v1=(a*vin+2.0*massj*vjn)/b         ! 一维弹性碰撞（动量守恒）
        v2=(-a*vjn+2.0*massi*vin)/b
        nodex(4,ni)=v1*nx+vit*tx           ! 直接改写两端速度
        ...
    end if
end if
```

两层含义：`rn_limit` 是"软"手段（距离越近排斥越强），`rn_rebound` 是**硬约束**
（速度层面直接禁止继续接近）。在 DEM 里，`r0` 对应接触距离 `d0 = r_a + r_b`。

## 3. Zaran3 的实现

### 3.1 参数

| 参数 | 默认 | 对应 LSM | 含义 |
|---|---|---|---|
| `dem.contact_stiffen_ratio` | **0.6** | `rn_limit/r0 = 0.6` | `dist < ratio·(r_a+r_b)` 时把法向排斥力乘以 `(ratio·(r_a+r_b)/dist)^20`。`0` = 关闭 |
| `dem.contact_rebound_ratio` | **0.6** | `rn_rebound/r0 = 0.5` | `dist < ratio·(r_a+r_b)` 且两端仍相向运动时，按弹性碰撞改写两端法向速度。`0` = 关闭 |

> **回弹阈值为何取 0.6 而不是 LSM 的 0.5** —— 见 §3.5 "封缝判据"：
> 当**加载边界由离散球排构成**时，0.5 不足以封住缝隙，实测 10 万步后仍有 30/30 个粒子逃逸；
> 0.6 则为 0/0。想严格复刻 LSM 可显式写
> `contact_stiffen_ratio = 0.6` / `contact_rebound_ratio = 0.5`。

> **关于 `^20` 放大**：它与回弹是配套的——放大从阈值处平滑起步（倍数从 1 开始增长），
> 到回弹阈值即被速度回弹截住，因此**实际倍数远小于上限**，不会往接触点注入额外动能。
> 巴西盘算例实测：开启后 `max|v| = 0.250 m/s`，与完全关闭时相同
> （唯一区别是关闭时有粒子被抛出而出现 `0.516 m/s`）。

参数校验（`DEMSolverParam::Init()`）：
- 两个 ratio 必须落在 `[0, 1)`，否则抛 `ZaranError("DEM contact overlap-limit ratios must be in [0, 1)")`；
- 同时启用时要求 `contact_rebound_ratio < contact_stiffen_ratio`（先放大、后回弹）。

### 3.2 刚性回弹（`ApplyContactRebound`）

触发条件：`dist < ratio·(r_a+r_b)` **且** `v_n = (v_b − v_a)·n < 0`（仍在接近）。

目标是把法向相对速度由 `v_n` 改为 `−e·v_n`（`e = min(e_a, e_b)`，即两粒子的恢复系数），
再按线动量守恒分配给两端。由 `m_a·α_a + m_b·α_b = 0` 与 `(α_b − α_a)·n = Δv_n` 解得：

```
α_a = −Δv_n · m_b/(m_a+m_b)      α_b = +Δv_n · m_a/(m_a+m_b)      Δv_n = −(1+e)·v_n > 0
```

- **规定运动粒子按无限质量处理**：`A` 或 `B` 为 `kinematic`/非 `active` 时，由另一侧
  独立承担全部修正，规定运动粒子自身速度不变（因此压板不会被粒子推走）。
- 对 LSM 的 `e = 1`（纯弹性）：本实现取两粒子的恢复系数，使这道保护不与
  `restitution_coeff` 的标定相矛盾；要完全复刻 LSM 可把 `restitution_coeff` 设为 `1`。
- 只改**线速度的法向分量**，不动切向与角速度，线动量严格守恒。

### 3.3 排斥力放大（`AmplifyDeepOverlapForce`）

`dist < ratio·(r_a+r_b)` 时：`contact.force_n *= (ratio·(r_a+r_b)/dist)^20`，
并加上限 `1e6` 与有限性判断，避免两端几乎完全重合时出现 `inf/NaN`。

### 3.4 在时间步中的位置与顺序
`DEMSolver::CalcContactForce()` 的每个接触对，严格按 LSM 的顺序：

```
ApplyContactRebound(pa, pb, c)        // ① 深压缩刚性回弹（先改速度）
CalcNormalForce(pa, pb, c, dt)        // ② 法向力（阻尼项因此用的是"回弹后"的相对速度）
AmplifyDeepOverlapForce(c, r_a+r_b)   // ③ 过深时放大 contact.force_n
CalcTangentialForce(pa, pb, c, dt)    // ④ 切向：库仑上限取 force_n 的模 → 同步放大
SaveContactHistory(c)
```

顺序要点：
- ① 在 ② 之前，使法向阻尼用回弹后的相对速度（同 LSM）；
- ③ 在 ④ 之前，使切向库仑摩擦上限 `μ·|F_n|` 用的是放大后的法向力（同 LSM）。

其余流程（`ZeroForce → CalcBondForce → ContactDetection → … → Integrate`）不变。
仅作用于**粒子-粒子**接触（对应 LSM 的节点-节点两体模块）；墙面接触（`CalcWallForce`）
不受影响。

### 3.5 封缝判据：为什么 0.5 挡不住"离散球压板"

一旦"深穿透"被消除，**残留的穿透往往来自边界本身的几何**，而不是接触模型。
以巴西盘的压板为例，它是一排**恰好相切**的离散球：

```
压板球半径  R_b = 3.781e-4 m      球心间距 = 2·R_b = 7.562e-4 m
试件粒子半径 R_p = 3.308e-4 m     接触距离 d0 = R_b + R_p = 7.089e-4 m
```

因为 **球心间距 > 试件粒子直径**，这排球其实是一道"带缝的栅栏"：
试件粒子可以从相邻压板球的**尖角缝隙**绕过去——只要它的中心被允许靠近到
压板球心 `R_b` 以内。于是"封住缝隙"的条件是

```
ratio · d0 > R_b            ⟹     ratio > R_b / (R_b + R_p) = 0.533
```

`ratio = 0.5` 时 `0.5·d0 = 3.545e-4 < 3.781e-4`，缝隙仍然通；`ratio = 0.6` 才封住。
（这条判据对"由离散球排构成的边界"普遍成立；等径球时为 0.5。）

**结论**：`ratio` 不只是"防深穿透"，它同时决定**离散球边界是否可穿**。
若某算例的边界球比试件粒子大得多，需要相应提高该值，或按 §6 从几何上把边界做成真正的面。

### 3.6 让粒子"外部相切"后，判据自动收紧

如果按"**相邻粒子恰好外切**"生成算例（试件半径 = 0.5·晶格间距，使 2r = 间距），
试件粒子变大，尖角缝隙相对更窄，判据 **R_b/(R_b+R_p) 自动下降**：

| 算例 | 试件半径 / 间距 | 压板半径 R_b | 判据 `R_b/(R_b+R_p)` | 默认 0.6 |
|---|---|---|---|---|
| 旧（`0.35·spacing`） | 3.308e-4 / 9.453e-4 = 0.70 | 3.781e-4 | **0.533** | 仅刚好封住 |
| **新（`0.50·spacing`）** | 4.726e-4 / 9.453e-4 = **1.00** | 3.781e-4 | **0.444** | 有充足余量 |

而且试件本身在粒子尺度上由"留缝"变成**封闭密排体**（相邻粒子精确外切，
29635 对键合的中心距与 `r_a+r_b` 的最大偏差为 5.6e-18，机器精度）。
`generate_case.py` 中已把该约定固化，并写进 `verify.py` 作为回归守护
（同时校验压板球彼此外切、以及 `0.6 > R_b/(R_b+R_p)`）。

`dem_brazilian_disk_test`（中等规模）同样改为 `PARTICLE_RADIUS = 0.5 * SPACING`：
85 个试件粒子、222 条键，相邻对中心距误差 5.2e-18；物理校验通过
（轴向收缩 `-1.962e-4 m`、中心横向拉应变 `+2.51e-3`、上下反力 `±8.591 N` 失衡 `0.000`）。

> **改半径时的一个坑（务必注意）**：不要顺手把"外轮廓过滤"也收紧。
> 起初把 `DISK_RADIUS - 0.35*SPACING` 改成 `DISK_RADIUS - 粒子半径`（看似更"正确"），
> 结果试件顶排只剩 x=±0.005 两个粒子，而压板球心落在 0.008 的整数倍上，
> 最小中心距恒为 `9.155e-3 > r_a+r_b = 9.0e-3` → **压板永远接触不上试件**，
> 算例因"轴向未收缩"而失败。回退过滤条件后（保留 x=±0.015 的顶排粒子，
> 与压板 x=±0.016 的球仅差 `dx=0.001`），压板下行 `1.55e-4` 即接触，加载恢复正常。
> 结论：**改变粒子半径时，必须复核压板球与试件顶排的 x 向对齐关系**。

## 4. 与 `dem.rigid_boundary` 的分工

两者互补，可同时开启：

| | `dem.rigid_boundary` | `dem.contact_rebound_ratio` |
|---|---|---|
| 层面 | **几何/力方向** | **速度/接近距离** |
| 作用 | 对"动态粒子 ↔ 规定运动粒子"的接触改用固定法向（取刚体运动方向），重叠按该法向投影 | 对任意粒子对，在过近时按弹性碰撞改写法向速度 |
| 解决的问题 | 法向随中心连线翻转 → 接触力由"压入"变"抛出" | 从根上不允许靠得过近，法向不会翻转 |
| 默认 | `false` | `0.5`（开启） |

建议：含**位移控制离散球压板**的算例两个都开；
`contact_rebound_ratio` 单独开启已足以消除穿透失效模式。

### 5.4 回弹阈值扫描：验证"封缝判据"

同一算例、压板速度 ×5、**10 万步（压板行程 5 mm）**，只改 `contact_rebound_ratio`
（`contact_stiffen_ratio = 0`，以隔离变量）。"逃逸"按严格口径统计 =
**整颗粒子完全处于压板行的外表面之外**：

| `contact_rebound_ratio` | `min dist/d0`(末帧) | 深重叠对 | **逃逸粒子（上/下）** | 封缝？ |
|---|---|---|---|---|
| `0.5`（= LSM `rn_rebound`） | 0.339 | 52 | **30 / 30** | ✗ |
| **`0.6`（默认）** | 0.439 | 14 | **0 / 0** | ✓ |
| `0.7` | 0.362 | 20 | **0 / 0** | ✓ |

与 §3.5 的判据 `ratio > R_b/(R_b+R_p) = 0.533` 完全吻合：`0.5` 不封缝，`0.6` 起封住。
同一次扫描还确认：本算例**试件内部没有任何粒子-粒子接触**
（晶格间距 9.5e-4 > 接触距离 6.6e-4，试件完全靠 29635 条键合维系），
因此提高下限**不会干扰试件本身的力学**，只作用于压板-试件接触。

> 注意 `below-floor`（压板对中 `dist < 0.6·d0` 的对数）会随压缩增长到 94，
> 这是正常的：回弹只阻止**继续接近**，已经处于下限内的对若在分离或侧向滑动就不会被干预。
> 判据应看 `ESCAPED`，而不是 `below-floor`。

## 6. 使用建议

```toml
[dem]
# 默认即已开启（按 LSM 取值），无需显式配置；
# 如需关闭或调整：
# contact_rebound_ratio = 0.5      # 硬约束：最近距离截在约 0.5·(r_a+r_b)；0 = 关闭
# contact_stiffen_ratio = 0.6      # 过深时放大排斥力；0 = 关闭
# rigid_boundary = true            # 叠加：把位移控制压板按刚性平面处理
```

其余可选手段（根因层面）：
1. **把加载边界做成真正的面**（最彻底）：让压板球相互重叠布置（球心间距 < 2·R_边界）、
   或加厚到多排，或直接改用平面墙（`DEMWall`，法向固定）——这样就不依赖 `ratio` 去封缝；
2. **让键合刚度与接触刚度自洽**：使 `kn` 与 `2·E*·R*` 同量级，避免"试件比夹具硬"；
3. 控制压板行程不超过 `r_a+r_b`；
4. 若仍要保留离散球压板，按 §3.5 判据 `ratio > R_b/(R_b + R_p)` 设定阈值。
