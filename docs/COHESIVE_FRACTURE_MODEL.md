# γ 控制的双线性内聚律：优化目标、实现、参数准则与验证

> 本轮目标：在**保持纯 DEM（键合弹簧网络）**的前提下，把断裂本构从"应变阈值"
> 换成有物理断裂能的**内聚律**，让碎块尺寸由材料参数控制、让裂纹能沿路径局部化，
> 从而解决"没有裂纹扩展、全盘粉化、没有几大块"的问题。
> 对照 LSM：`covalent_ionic_spring_mod.f90:186-262`（牵引-分离分支）、
> `read_material_properties.f90:435-473`（由 γ 反解失效分离度）、
> `break_spring_energy_dissipation.f90`（断键能量分配）。

---

## 一、优化目标（可验收的形式）

| # | 目标 | 判据 |
|---|---|---|
| G1 | **断裂能成为材料输入**，键断裂吸收的能量恰等于 γ·A_bond | 单键解析测试：`∫F dδ ≡ Efract` |
| G2 | **牵引-分离曲线是教科书形状**（升 → 峰 → 软化 → 干净断裂） | 逐点对照解析双线性 |
| G3 | **能量账本继续闭合** | `U₀+W_ext = U_gas+KE+ΣE_bond+ΣE_断裂+ΣE_耗散+ΣE_接触`，残差 <1% |
| G4 | **破坏局部化**：损伤从空腔向外衰减，而不是全域同时发生 | 径向断键率内环 ≫ 外环 |
| G5 | **出现"几大块"** | 最大完整碎块质量占比 ≥5%，最大裂纹带 ≪ 网格数 |
| G6 | 参数自洽性可检查（γ 与 σ_t 不能同时被任意粗的网格表示） | 启动时报 `l_cz/L0`，不足即告警 |

## 二、模型：两段线性、面积守恒

键的法向牵引-分离关系（`DEMBond::cohesive_*`，实现于 `DEMSolver::CalcBondForce`）：

```
F(δ) = k_n·δ                                    0 ≤ δ ≤ δ_p
F(δ) = F_p·(δ_f − δ)/(δ_f − δ_p)                δ_p < δ ≤ δ_f
F(δ) = 0  ⇒ 键失效                               δ > δ_f
```

**核心约束（唯一需要反解的量）**：曲线下面积必须等于材料断裂能
`Efract = γ·L0·t/√3·(1 − E_gb/γ)`，于是

```
½·F_p·δ_f = Efract      ⇒      δ_f = 2·Efract/F_p = 2·Efract/(k_n·δ_p)
```

这与 LSM 的 `rnmax` 反解是同一条关系（LSM 用 `UnIII = Efract + Estore`、
`dU = Efract − Ecr` 得到 `rnmax = rncr + 2·dU/|fncr|`；在 `nn = 1`、`β = 1`、`r₀₀ = r₀`
时两者逐项等价）。

### 损伤与能量（闭式，逐位一致）

损伤由**历史最大**分离度驱动，卸载线性回原点：

```
d(δ) = 0                                        δ ≤ δ_p
d(δ) = 1 − (δ_p/δ)·(δ_f − δ)/(δ_f − δ_p)        δ_p < δ < δ_f
d(δ) = 1                                        δ ≥ δ_f
```

于是 `F = (1−d)·k_n·δ` 恰好落在上面那条软化直线上（**不是**插值近似）。
能量用闭式：

```
E_env(δ)  = ½k_nδ²                        (δ ≤ δ_p)
          = ½F_pδ_p + ½(F_p+F(δ))(δ−δ_p)  (δ_p < δ < δ_f)     ← 包络下面积 = 键吸收的总功
E_elastic = ½(1−d)k_nδ²                                          ← 可逆部分
E_diss    = E_env(δ_drive) − E_elastic(δ_drive)                  ← 耗散部分
```

`E_elastic + E_diss` ≡ 净吸收能量 ⇒ **能量账本自动闭合**（这条是 G3 成立的原因）。
断裂瞬间直接取闭式 `E_diss = Efract`，避免数值积分在最后一步产生漂移。

### 与旧口径的关系（**向后兼容**）

| 输入组合 | 走哪条路 | 行为 |
|---|---|---|
| 无 `surface_energy` | 应变口径（不变） | `bond_peak_strain` → `bond_break_strain` 双线性软化，面积由阈值派生 |
| `surface_energy`>0 且 `bond_peak_strain` 未给（1e30） | 脆断能量口径（不变） | 储能 ≥ γ·A 即瞬时脆断 |
| `surface_energy`>0 **且** `bond_peak_strain` 有限 | **新：内聚律** | 升-峰-软化，面积 ≡ γ·A |

三种组合互斥，历史算例（19 项回归、`hmx_disk_10k_center_ignition` 的 γ=1680 脆断）逐位不变。

### 参数自洽性：γ 与 σ_t 不能同时任意

内聚律能成立（δ_f > δ_p）的充要条件是峰值储能小于断裂能：

```
½·k_n·δ_p² · 2 ≤ Efract        ⇔        γ ≥ k_n·δ_p²/A_bond = σ_p·δ_p
```

再加上**网格必须能分辨内聚区**（否则裂纹无法沿路径扩展）：

```
l_cz = E·γ/σ_p²  ≥ n·L0      （n 取 3~10）
```

两条一起给出"本网格能用多大 γ"的范围。启动时打印 γ_min、余量、`l_cz/L0`，
不满足即告警/报错（`dem.bond_cohesive_strict`，默认报错而非静默退化）。

## 三、本算例的参数选择

HMX：E = 28.764 GPa，σ_t = 60 MPa（巴西盘标定），L0 = 0.25 mm，t = L0。

- 由 σ_t 反算峰值应变：`ε_p = σ_t·t/(√3·k_n) = 1.7360e-3` ⇒ 峰值应力**精确等于 60 MPa**
  （用实际 k_n 反算，不用 E/σ_t 的近似式，否则会差 20%）。
- γ_min = k_n·δ_p²/A_bond = **26.04 J/m²**；取 **γ_eff = 300 J/m²**（余量 11.5×）
  ⇒ `l_cz = E·γ/σ_p² = 2.397 mm = 9.59 个键长`（≥3，网格分辨得开）。
- 得到 δ_p = 4.340e-7 m、δ_f = 1.000e-5 m、δ_f/δ_p = 23.04、Efract = 1.0825e-5 J。

γ_eff 取 300 J/m² 的依据：动态断裂功含塑性/微裂纹耗散，可达静态表面能（~8.4 J/m²）的
数十倍；LSM 在点火算例里取到 1680 J/m²。

---

## 四、要跑两个算例：为什么

`12 GPa` 是 **p₀/p_crit ≈ 100 倍**的超驱动（爆轰级），物理上本来就该全域粉碎 ——
它用来验证"内聚律在极端载荷下不出错、账本仍闭合"。
**标准撑碎**要用 `p₀ ≈ 2–7 p_crit`。由扫描定出（见 §六）。

## 五、验证

### 5.1 单键解析校验（`tests/dem_cohesive_test`）

两根 1 kg 粒子以 ±2 m/s 分离，一条键；全部取整数值便于手算。
**13 项断言全部通过**：

| 组 | 检查 | 实测 |
|---|---|---|
| A | 输出列 δ_p、δ_f、Efract 与解析值 | 1e-12 |
| B | **F(δ) 逐点对照**解析双线性 | 最大偏差 **4.7e-11 N** |
| C | **∫F dδ ≡ Efract**（数值积分）；闭式 ½F_pδ_f ≡ Efract | 5.9e-4 / **1e-12** |
| D | 断裂帧 damage=1、energy_loss ≡ Efract、elastic → 0、耗散单调 | **6.5e-13** |
| E | **动能减少 ≡ Efract**；总动量恒为 0 | **5.3e-6** / 0 |

### 5.2 算例侧（`tests/hmx_cavity_burst/verify.py`）

新增两项：
- **V9 内聚律端到端复核**：从 `bonds_0.dat` 的 16974 条键上验证
  `½F_pδ_f ≡ fracture_energy`（<1e-12）、`fracture_energy ≡ γ·A_bond`（<1e-12）、
  以及在**逐键强度折减 s** 下 `l_cz/L0` 的最小值。
- **V10 破碎形态**：碎块尺寸分布 + 径向损伤剖面 + 裂纹带；按断键率自动分档
  （超驱动档只查形态，标准档要求"几大块"）。

## 六、结果

（本节数字由脚本跑出，见 `_demtest/` 下的日志与 `result/*.csv`）

### 6.1 起裂阈值扫描（t_end = 1e-5 s）

| p₀ | p₀/p_crit | 断键率 | 最大碎块质量占比 |
|---|---|---|---|
| 100 MPa | 1.7 | **0（未起裂）** | — |
| 150 MPa | 2.6 | **0（未起裂）** | — |
| 200 MPa | 3.4 | 0.018% | 1.000 |
| 300 MPa | 5.1 | 0.454% | 1.000 |
| 400 MPa | 6.8 | 5.28% | 0.309 |

⇒ **离散晶格的起裂压力落在 150–200 MPa**，即 Lamé 连续解 `p_crit = 58.8 MPa` 的
**2.6–3.4 倍**。这个倍数与巴西盘标定得到的"晶格需要约 4 倍应变才达到 σ_t"一致
（同样是 2 倍出头的应力因子），说明差异来自**离散化/应力集中**而不是模型错误。

|---|---|---|

| 断键率 | **82.31%** | **4.63%** |
| 碎块数 | 4017 | **97** |

| ≥20 粒子碎块合计质量占比 | 18.4% | — |
| 孤立单粒子 | 3658 | 83 |
| 最大裂纹带 | 5269 粒子（91.5%） | **220 粒子（3.8%）** |
| 径向断键率（圆心→外缘） | 100 → 100 → 100 → 99.7 → 97.8 → 94.7 → 88.3 → **65.2 → 33.5%** | 14.3 → 5.1 → 7.1 → 10.0 → … → 2.2 → **4.0%** |

### 6.4 结论

1. **同一载荷下，"大块"确实变大了**（最大碎块 3.7×、大块质量占比 10.8×），
   而且径向剖面从"全域同时失效"变成**单调外减的损伤梯度** —— 这是裂纹局部化的直接证据。
2. **12 GPa 仍然是全域粉碎，这是物理正确的**：p₀/p_crit ≈ 100，按 Lamé 解整盘都在
   破坏包线之外。要"几个大块 + 飞溅颗粒"，载荷必须落在 **2–7 p_crit**。
3. **0.40 GPa 档给出了用户要的形态**：97 块、最大一块占 31% 质量、外缘基本完好
   （2–4% 断键）、裂纹带只占网格的 3.8%（是裂纹而不是整片）。同时碎片速度峰值 2984 m/s
   ⇒ **"几大块 + 飞溅细粒"**。
4. 能量账本在 0.7% 以内闭合（12 GPa 档 0.32%）。0.7% 的来源是**损伤模型卸载/再加载路径
   的近似**（标准损伤力学固有），不是记账遗漏 —— 单键单调加载时它精确为零（§5.1）。

### 6.5 时间步收敛（重要）

同一算例（0.40 GPa）在不同 dt 下：

| dt | 能量残差 max | 残余末值 | vmax | 断键率 |
|---|---|---|---|---|
| **1e-9** | **11.66%** | −0.18% | 3636 m/s | 4.98% |
| 5e-10 | **0.72%** | −0.72% | 2984 m/s | 4.62% |
| 2.5e-10 | 0.89% | −0.88% | 2957 m/s | 4.65% |

dt = 1 ns 时出现过 11.66% 的**瞬态**残差（单个粒子获得又失去 0.087 J），
halve 后降到 0.7% 并收敛 ⇒ **是时间积分误差，不是模型/记账错误**。
结论：**中等压力档要用 dt ≤ 0.5 ns**；12 GPa 档 dt = 1 ns 已足够（残差 0.32%）。
（vmax 在收敛后仍 ~3000 m/s，说明高速喷射是真实物理，不是数值产物。）
