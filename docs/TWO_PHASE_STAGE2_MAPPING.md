# 粒子 → 网格映射（阶段 2）—— 实现与验证

> 阶段 2 的目标：把 DEM 粒子的体积**精确地、尽量光滑地**分配到流体的均匀笛卡尔网格上，
> 并同时建立后续相间力所必需的两个算子。
> 验收标准：**体积精确配分（Σα·V_cell = ΣV_p）+ 网格加密后收敛到真实体积分数**。

- 映射器：`ParticleGridMapper`（`inc/Basic/TwoPhase/` + `src/Basic/TwoPhase/`）
- 基准驱动：`benchmarks/two_phase_mapping/mapping_main.cpp`（独立 CMake target `MappingBench`）
- 验证脚本：`benchmarks/two_phase_mapping/verify_mapping.py`（六项检验）
- 上游阶段 1（ε 加权 Euler 求解器）：见 `docs/TWO_PHASE_EULER_STAGE1.md`

`ParticleGridMapper` 是**纯几何工具**，不含任何求解器状态，因此可以被验证到机器精度，
也不参与主程序的求解流程（但会随 `src/*.cpp` 一起编译进主程序，随时可供耦合层调用）。

## 1. 单元约定（必须与 CFD 侧一致）

阶段 1 的求解器是**节点型有限体积**：物理量存在网格节点上，残差是
`dU_i/dt = -(F_{i+1/2} - F_{i-1/2})/Δx`，即每个节点承担一个体积为 `dx·dy·dz` 的**控制体**。
因此本映射器的 **单元中心 = CFD 节点坐标**；整个计算域是

```
[x0 - dx/2, x0 + (ni - 1/2)·dx] × [y0 - dy/2, ...] × [z0 - dz/2, ...]
```

比节点跨度**多出半个单元**。DEM 侧的计算盒应当覆盖这个范围（阶段 3 的耦合驱动负责校验）。
2 维时把粒子当圆盘，单元面积取 `dx·dy`（厚度 1）。

## 2. 两种分配方法

两者都由**构造**保证体积精确守恒，但代价与精度不同。

### 2.1 `SubCell(n)` —— 便宜，CFD-DEM 的标准做法

把粒子沿每轴切成 `n` 份（共 `n³` 个小立方体），每个小立方体把自己的体积 `V_p/n³`
**整体**记到"包含其中心"的那个单元。`n = 2` 就是经典的**八分体法 / 粒子中心法**
（Hoomans 1996、Link 2011），每个粒子最多触及 8 个单元。

**守恒为什么精确**：`V_p` 被切成互不重叠、不漏的 `n³` 份，每份只落进唯一一个单元。

**适用条件**：该方法把粒子"抹"成 `n³` 个点质量，只有在 **Δx ≥ 3–5 d_p**（体积分数法的
经验下限）时才有意义。Δx ≪ d_p 时它会把整块体积压进少数单元（α 可以远大于 1），
此时必须加大 `n` 或改用 `Exact`。

### 2.2 `Exact` —— 精确单元平均，用作参考解

直接算**球与单元长方体的交集体积**，再除以单元体积。这是该网格下单元平均体积分数的
**定义值**，因此它同时充当其它方法的真值。

**降维**：沿 x 做 1 维积分

```
V = ∫ A_rect∩disk(ρ(x)) dx,      ρ(x) = √(R² - x²)
```

`A_rect∩disk` 有闭式解（矩形按坐标轴切成 ≤4 个象限子矩形，每个子矩形用
`1_{a≤y≤b} = 1_{y≥a} - 1_{y≥b}` 的四项容斥，落到"正下界角区面积"

```
P(u,v,ρ) = ∫_u^Y (√(ρ²-y²) - v) dy,  Y = √(ρ²-v²)
         = ½(Yv) + ½ρ²·acos(v/ρ) - ½u√(ρ²-u²) - ½ρ²·asin(u/ρ) - v(Y-u)
```

上）。为消除 `x = ±R` 处 `√` 造成的半幂奇性，再换 `x = R·sinθ`，于是

```
V = ∫ R·cosθ · A(R·cosθ) dθ
```

### 2.3 ⚠️ `Exact` 里踩的三个坑（都已修）

断点若取不全，被积函数在段内仍有折点，高斯积分的收敛会退化成代数收敛（而且很慢）。
用**纯配分恒等式**（球完全落在网格内时 `Σ_cells V = 4πR³/3`）扫参数，实测：

| 断点取法 | Δx/R=0.5 | Δx/R=1.0 |
|---|---|---|
| 只用 `asin(e/R)`（错）| 2.4e-8 | 1.8e-7 |
| 改用 `acos(\|e\|/R)` | — | — |
| `acos` + **补上角点 ρ=√(y_i²+z_j²)** | **4.2e-11** | **3.0e-9** |

三个坑：

1. **断点位置用错**：`ρ(θ) = R·cosθ`，要 `ρ = |e|` 应取 `θ = ±acos(|e|/R)`，**不是** `asin`。
2. **漏了一类断点**：除"圆盘扫过矩形四条边"（`ρ = |y_i|, |z_j|`）之外，还有
   **"圆盘扫过矩形四个角点"**（`ρ = √(y_i²+z_j²)`）——`CornerArea` 里的 `min(u, Y)` 与
   `u²+v² ≥ ρ²` 两个分支都在这里切换。
3. **断点数组开小了**：完整断点集最多 2 + 8×2 = 18 个，原来只开了 6 个 ⇒ **栈越界**
   （Windows 直接 `0xC0000409` 静默崩溃）。同类错误还有 `DiskRectArea` 里的
   `ys[3]` 要装 2 个子区间 × 2 个端点 = 4 个值 —— 一并改成 `ys[4]`。

另外加了两个**精确早退**（单元整块在球内/球外时直接返回解析值），既省时间又消掉
小单元情形下的主要误差来源。

**最终精度**（24 点 Gauss-Legendre）：Δx ≥ 2 d_p 时配分残差 **~1e-15**（机器零）；
粒子大于单元（Δx ≈ 0.45 d_p）时 ~2.6e-11（受临界相切单元的高斯积分限制）。
**单点精度与 K 无关**（K=16…64 给出同一值），说明分段是完备的。

## 3. 保守光顺（可选）

`SubCell` 的场是逐单元常数，相邻单元会有跳变。光顺用**通量型 Laplacian**：

```
每个面 (c0,c1)：  f = (α_c0 - α_c1)·k,     α_c0 -= f,  α_c1 += f      (k = 1/(2·dim))
```

**Σα 逐位不变**（每个面的两个半操作加减同一个 `f`），边界取零通量（Neumann）也守恒。
最终结果按 `(1-θ)·α_raw + θ·α_smooth` 混合 —— 两者总和相同，因此混合仍然守恒，
且不会引入负值（原始场非负时）。

实测（Δx/d_p ≈ 0.8，`SubCell(2)`）：最大跳变 `9.98e-1 → 1.87e-1`（1 次）`→ 1.33e-2`（16 次），
而 Σα 的相对变化始终 ≤ 3.8e-14（纯累加舍入）。

## 4. 力散射与对偶插值（阶段 3 的两个算子）

三个操作共用**同一套权重**（`Σ_c w_c = 1`）：

| 操作 | 作用 | 精确性质 |
|---|---|---|
| `ComputeSolidFraction` | α_c = Σ_p w_pc·V_p/V_cell | ΣαV = ΣV_p（构造保证） |
| `ScatterParticleVector` | F_c = Σ_p w_pc·F_p | **Σ_c F_c = Σ_p F_p**（动量守恒） |
| `GatherToParticle` | F_p = Σ_c w_pc·F_c | 常数场插值回原值（Σw = 1） |

后两条是**阶段 3 相间力耦合守恒的前提**，而且不需要任何曳力模型就能单独验证 ✓。

## 6. 验证结果

六项全部通过（`verify_mapping.py`；`--quick` 可粗算冒烟，完整跑约 2 分钟）。

### M1 精确配分（40³ 网格，800 粒子，r=0.03，Δx/d_p≈0.45）

| 方法 | n | 实际分配体积 | 配分残差 | 判定 |
|---|---|---|---|---|
| SubCell | 1 | 9.047786842339e-02 | **0.000e+00** | ✅ |
| SubCell | 2 | 9.047786842338e-02 | 9.2e-14 | ✅ |
| SubCell | 3 | 9.047786842342e-02 | 3.5e-13 | ✅ |
| SubCell | 4 | 9.047786842349e-02 | 1.1e-12 | ✅ |
| SubCell | 8 | 9.047786842311e-02 | 3.0e-12 | ✅ |
| **Exact** | — | 9.047786842105e-02 | **2.6e-11** | ✅ |

`ΣV_p = 9.047786842339e-02`。SubCell 的残差随 `n` 缓慢上升（`n=8` 时每个粒子做 512 次加法、
全场合计 ~4×10⁵ 次），**是纯累加舍入**，不是守恒性缺陷。Exact 的 2.6e-11 是 1 维高斯积分的
极限精度，在该网格（粒子比单元还大）下已远超任何物理需要。

> ⚠️ 本算例的 `α_max` 达 2.5，看起来违反物理。**这不是几何错误**：随机粒子云没有做非重叠
> 约束（粒子互相重叠），而单个粒子对任一单元的贡献恒 ≤ 1。真实 DEM 堆积不会出现这种情况。

## 7. 方法选择：Δx/d_p 决定用哪一个

由 M2 的实测（`subcell` 相对 `exact` 的 L1）：

| Δx/d_p | SubCell(2) | SubCell(4) | 建议 |
|---|---|---|---|
| ≥ 3 | ≲ 1e-2 | ≲ 1e-2 | **SubCell(2)** 足够，最便宜（≤8 单元/粒子） |
| 1 – 3 | ~1e-1 | ~1e-1 | SubCell(4) 或 Exact |
| 0.5 – 1 | ~2e-1 … 6e-1 | ~1e-1 | **改用 Exact** |
| < 0.5 | O(1)（`L∞` 到 1e2） | O(1) | 体积分数法已失效，需转点源法 |

这与文献的经验下限（体积分数法要求 `Δx ≥ 3–5 d_p`）一致，但这里是**实测出来的**。
建议耦合算例把 `Δx/d_p` 打印进日志，作为一项常规自检。

**代价参考**：`SubCell(2)` 每粒子 ≤ 8 个单元；`Exact` 每粒子 ≤ 27 个单元，每个单元
最多 ~18 个积分段 × 24 点高斯 ⇒ 约两个量级的开销。因此 `Exact` 定位为**参考解与
中等规模算例**，生产算例在 `Δx ≥ 3 d_p` 时应使用 `SubCell`。

## 8. 局限与阶段 3 的接入点

**当前局限**

1. 粒子云假定**球、等径或异径皆可**，但不支持非球形/多面体颗粒（映射器的接口是
   `(x,y,z,r)`，扩展到凸多面体需要换掉体积交集的实现）。
2. 映射只写**物理单元**（节点）范围；粒子若跨出计算域，超出部分直接丢掉（`assigned < ΣV_p`
   会被统计量暴露）。阶段 3 应校验 DEM 盒覆盖 CFD 的控制体范围（比节点跨度多半格）。
3. 光顺只作用于 ε。若要在曳力里用光顺后的 ε 当权重，需把同一光顺算子也作用到力上
   （线性、保总量）——建议在阶段 3 里一次性定下这件事。
4. 单机 OpenMP 下的散点累加（`α_c += ...`、`F_c += ...`）目前是串行的。多线程需要
   分块私有数组或原子加——与阶段 1 提到的"粒子→网格力映射的多线程归约"是同一件事。
5. 无空间索引（每粒子按包围盒直接遍历单元）。粒子多、网格细时应加 cell list
   （DEM 侧已有 `BuildUniformGrid`，可复用其思路）。

**阶段 3 的接入点**

- ε 场：`ComputeSolidFraction` 的输出 `α_s` 取 `ε_g = 1 - α_s`，直接写进
  `DataManagerNSTwoPhase` 的 `volume_fraction` 数组即可（阶段 1 已经把这个数组接进
  通量加权与变量转换）；
- 相间力：`ScatterParticleVector` 的输出加到 `CalcSourceResidual()`（阶段 1 里是空实现），
  与通量残差同一层级、同样参与 RK 子步；
- 流体→粒子：`GatherToParticle` 插值速度/压力到粒子位置，供曳力与 `∇p` 力使用；
- 时间步：DEM 的 `dt ≈ 1e-8 s` 与 CFD 的 `dt ≈ 1e-6–1e-7 s` 差 1–2 个量级，
  需要在 `CalcMinTimeStep` 之后做子循环 + 相间力的时间平均。

**下一步建议**：先做**单向耦合**（曳力 + `∇p` 力，只从流体到颗粒），把曳力模型
（Ergun / Wen–Yu / Gidaspow + 可压缩修正）与 `∇p` 力的重合问题确认清楚，再加反作用。
验证阶梯的第 1–2 级（单球阻力 `C_D–Re`、固定床压降 vs Ergun）都可以在现有结构上直接搭。
