## 1. 物理过程分解

| 环节 | 内容 | 本算例的取法 |
|---|---|---|
| **几何建模** | 直径 20 mm 的**正圆**样品，中心有直径 2 mm 的贯通空腔 | 二维平面（面外厚度 t）三角形晶格，节点用 DEM 球表示；中心 `d < a₀` 的节点一律不放置形成空腔；外轮廓按 `d ≤ R` 裁成正圆 |
| **材料模型** | HMX 脆性含能材料 | 永久弹性键 + 接触模型；`E = 28.764 GPa`、`ν = 0.2`、`ρ = 1890 kg/m³` |
| **高压气体加载** | 空腔壁受气体法向压力 p 作用 | **新增** `CavityGasModel`：空腔壁由「边界粒子环」离散，第 i 个粒子承受 `F_i = p·ℓ_i·t·n̂_i`；气体按绝热规律膨胀做功、压力随空腔体积下降 |
| **破碎判据 / 失效准则** | 炸药被撑碎 = 键断裂并形成碎块 | 键轴向应变：拉伸双线性软化后断裂（`bond_break_strain`）、压缩脆性判据（`σ_c/σ_t = 8`）；逐键 Weibull 强度异质性（m = 8）；碎裂后转由接触模型承载 |
| **网格 / 拓扑处理** | DEM 无网格重划分 | 键拓扑在 t=0 一次性建立；键断开后两端粒子仍保留，改由逐步接触检测承载（接触重叠限制作为兜底） |
| **时间尺度** | 需同时分辨应力波与断裂事件 | 弹性波速 `c = √(E/ρ) = 3901 m/s`，径向穿越 `2R/c = 5.13 μs`；空腔壁初加速度 `p·Σℓ·t/m ≈ 3.4e10 m/s²` |

**为什么"10 GPa 会把它撑碎"**：厚壁圆筒（内半径 a、外半径 R、内压 p、外表面自由）的环向应力

```
σ_θ(r) = p·a²/(R²−a²)·(1 + R²/r²)      ⇒   σ_θ(a) = 1.0202·p     （R = 10a）
σ_r(r) = p·a²/(R²−a²)·(1 − R²/r²)      ⇒   σ_r(a) = −p，σ_r(R) = 0
```

`p = 12 GPa ⇒ σ_θ(a) = 12.24 GPa`，是 HMX 抗拉强度（约 0.1 GPa 量级）的**百倍以上**；
按 `1/r²` 衰减到样品外缘仍有 `σ_θ(R) = 2·p·a²/(R²−a²) = 0.245 GPa`，仍超过强度。
所以**整个圆盘都落在破坏包线之外**，会被完全撑碎——实测断键率 94.0%，验证了这一判断。

## 3. 实现

### 3.1 新类 `CavityGasModel`

**物理模型**：空腔壁由**边界粒子环**离散。第 i 个粒子的内切半径 `ρ_i = d_i − r_p`，
角向分片宽度 `Δθ_i = ½(θ_{i+1} − θ_{i−1})`（环序在 t=0 按极角排定后固定；接缝处循环取法
保证 `ΣΔθ_i ≡ 2π`）。面段长度 `ℓ_i = ρ_i·Δθ_i`，外法向由腔心指向该粒子：

```
F_i = p · ℓ_i · t · n̂_i            （t = 平面外厚度）
```

**做功与体积的严格自洽**（能量账本能闭合的关键）：同一次几何刷新同时给出体积增量
（二维散度定理），并且受力与体积**共用同一套** `ℓ_i`、`n̂_i`：

```
ΔA = Σ_i ℓ_i (Δu_i · n̂_i)，ΔV = ΔA·t
⇒ Σ_i F_i·Δu_i = p·t·Σ_i ℓ_i(Δu_i·n̂_i) = p·ΔV        —— 逐位恒等
```

半隐式 Euler 下 `Δu_i = v_i^{n+1}·dt` 正是 `Integrate()` 用的位移。实测（逐步输出）：
`Σ p^n·ΔV^n` 与 `gas_work` 相对偏差 **5.8e-14**。

**状态方程**：状态量取内能 `U`（`U = pV/(γ−1)`），每步绝热做功更新 `U ← U − pΔV`，
再由 `p = (γ−1)U/V` 反解压力；连续极限即 `pV^γ = const`。`ramp_time > 0` 时升压段压力
按 `p₀·t/t_ramp` 强制给定，注入的能量单独计入 `external_work`。

**接口**

```cpp
void Initialize(const dynamic_array<DEMParticle>&, const CavityGasOptions&, double lattice_spacing);
void ApplyPressureForce(dynamic_array<DEMParticle>&, double time);   // 步首（积分前）
void UpdateState(const dynamic_array<DEMParticle>&, double dt, double time); // 步末（积分后）
```

**参数（全部在 `[dem]` 段）**

| 键 | 默认 | 含义 |
|---|---|---|
| `gas_cavity_enabled` | false | 总开关 |
| `gas_cavity_center_x/y/z` | 0 | 空腔中心 (m) |
| `gas_cavity_radius` | — | 初始空腔半径 a₀ (m) |
| `gas_pressure_initial` | — | 初始气体压力 p₀ (Pa) |
| `gas_polytropic_index` | 1.4 | 绝热（多变）指数 γ，必须 > 1 |
| `gas_ramp_time` | 0 | 升压时间 (s)；0 = 瞬时加载 |
| `gas_cavity_shell_tolerance` | 0.5 | 边界环识别容差（× 格距 L0）：判据 `d ≤ a₀ + r_p + tol·L0` |
| `gas_cavity_pressure_cap` | 0 | 压力上限 (Pa)；0 = 不限 |
| `gas_cavity_vent_area_ratio` | 0 | 泄压判据：空腔面积 /(πR²)；0 = 永不泄压 |
| `sample_radius` | 0 | 样品外半径 R (m)，供泄压判据使用 |

**输出**：`result/cavity_gas.csv`，每输出帧一行，26 列

```
iter, time, cavity_pressure_Pa, cavity_volume_m3, cavity_area_m2, cavity_area_geom_m2,
cavity_radius_eff_m, gas_internal_energy_J, gas_work_J, external_work_J,
kinetic_translation_J, kinetic_rotation_J, bond_elastic_J, bond_fracture_J,
dissipation_J, contact_elastic_J, rebound_loss_J, energy_residual_rel,
max_speed_m_s, max_fragment_distance_m, active_bonds, broken_bonds,
ring_particles, vented, gas_force_sum_N, ring_max_gap_rad
```

### 3.2 求解器接入点

```
DEMSolver::Solve()
    ZeroForce（含 m_tmp_dissipation / m_contact_elastic 清零）
    → CalcBondForce → ContactDetection → CalcContactForce → CalcWallForce
    → AdvanceContactHistory → CalcGravity → CalcThermalReaction → CalcGasPressureForce
    → CalcCavityGasForce(t)        ← 新增：积分**前**，用步初位置确定边界几何并施加面力
    → Integrate()
    → UpdateCavityGasState(dt, t)  ← 新增：积分**后**，用同一套 ℓ_i / n̂_i 更新 V 与 U
    → 累加机械耗散
```

`DEMSolver::GetEnergyBudget()` 给出键弹性能、键断裂耗散、机械耗散累计、**接触弹性能**、
**回弹保护移出的动能**、平动/转动动能、最大速率、最远碎片距离、完好/已断键数。

## 4. 算例：关键参数、边界条件、初始条件

### 4.1 几何与离散

| 量 | 取值 |

| 空腔直径 d / 半径 a₀ | 2 mm / 1 mm |

| 初始气腔 | A₀ = 2.9296e−6 m²，V₀ = 7.3241e−10 m³ |

### 4.2 材料（HMX）

| 量 | 取值 |
|---|---|
| 密度 / 杨氏模量 / 泊松比 | 1890 kg/m³ / 28.764 GPa / 0.20 |
| 摩擦系数 / 恢复系数 | 0.30 / 0.80 |
| 键法向/切向刚度 | kn = 4.9886e6 N/m，kt = 3.9010e6 N/m |
| 键抗拉断裂应变 | 3.0e−3（软化起点 1.5e−3） |
| 抗压/抗拉强度比 | 8.0（压缩断裂应变 2.4e−2） |
| 逐键强度异质性 | Weibull m = 8，种子 20260926（均值归一为 1） |
| 键合粘性 | η = 100 Pa·s |
| 高压硬化 | **关闭**（`high_pressure_knn = 0`）——理由见 §7.3 |

### 4.3 初始条件

* 所有粒子 `v = ω = 0`，`T = 300 K`，`reaction_progress = 0`（不点火，纯力学）。
* 空腔内气体：`p₀ = 1.2e10 Pa`（12 GPa > 10 GPa），`γ = 1.4`，
  `U₀ = p₀V₀/(γ−1) = 21.972 J`（模型输出与解析式相对偏差 1.3e−13）。
* `ramp_time = 0`：压力**瞬时**加满（对应"腔体内部已填充高压气体"的设定）。

### 4.4 边界条件

* **空腔内壁**：气腔压力面力（唯一的外载荷）。载荷合力恒为 0（径向压力沿封闭环积分）——
  独立复算得 `ΣF_gas/Σ|F| = 1.0e−16`。
* **样品外缘**：自由表面（不建键、不加约束）。
* **计算域盒** `[dem.box]`：**±30 mm**（`--box-pad-ratio 3.0`），净空 **20 mm = 2R**。
  盒面是刚性墙。留这么宽是必需的：碎片速度可达 ~1.7 km/s，`t_end = 1e−5 s` 内最多走
  17 mm；净空不足会让碎块过早撞墙、把动能弹回内部并破坏动量守恒检查。
* 无重力（`gravity_* = 0`）。

### 4.5 数值

| 量 | 取值 | 依据 |
|---|---|---|
| dt | **1e−9 s** | 键振动稳定限 `2√(m/kn) = 1.11e−7 s` 只是必要条件；空腔壁初加速度 3.4e10 m/s²，dt = 5 ns 时单步速度增量 170 m/s，能量账本在剧烈段会差 17%；1 ns 时降到 34 m/s，残差 < 0.4%（实测 dt 与 dt/4 之间 \|Δp\|/p = 0.86%） |
| t_end | 1e−5 s（10000 步） | ≈ 2× 径向应力波穿越时间（5.13 μs） |
| output_iter | 100 | 101 帧 |
| 接触模型 | LinearSpringDashpot | 碎裂后的碎块互撞 |
| 重叠限制 | stiffen 0.6 / rebound 0.6 | 深压缩兜底（其移出的动能单独计入账本） |

## 6. 已知适用范围

* **气腔体积用边界环多边形追踪**：环被完全撕开后（断键率 > 50%），散度定理的累积量与
  逐帧几何重算量分岔（实测 17.1%）。此时"空腔"只是气体占位的等效体积，压力已降到
  几十 MPa，对结果影响很小；`gas_cavity_vent_area_ratio` 可在气腔扩到自由面时终止加载。
* **动量在碎裂后允许 ≤1% 的漂移**：逐键 Weibull 强度无序使响应不再镜像对称，环的几何
  随之失对称，于是产生小净力。不破坏的弹性变体里这一项是机器零（W3 = 2.1e−13），
  所以这不是求解器的守恒性问题。
* **高压硬化支路关闭**（§7.3）：它只适合 LSM 那种大压缩冲击场景。

## 7. 调试中定位并修掉的问题

1. **（我的生成器）三角晶格键拓扑错了**：奇偶行沿用了同一套斜向偏移，使 **5424 / 16428**
   条键连成了 √3·L₀ 的**次近邻**。这些键的初始拉伸应变就是 0.732，第一步全部"断裂"、
   凭空释放 **453 J**（系统总共只有 22 J），能量账本虚高到 **2049%**。
   → 生成器补了**键长自检**（任何 ≠ L₀ 的键直接报错）。
2. **（我的生成器）样品上下被截平成直边**：行方向的上限沿用了 `ceil(R/L0)`，但**行距是
   (√3/2)·L₀**，于是只铺到 0.866·R（R = 10 mm 时 `|y|max` 只有 9.093 mm）。
   行/列上限分开算之后 `|y|max = 9.959 mm`，轮廓成为正圆。
3. **高压硬化支路在小压缩下是"软化"不是"硬化"**：LSM 移植来的 REP/HBP 支路是幂律
   `F = knn·kn·(δ/δ_ref)^(exp+1)`，`δ → 0` 处切线刚度为 0。本算例孔壁受压只有 ε ~ 1e−3，
   落在极软段（实测**只有线性刚度的 2.5%**），把径向传力路径整条掐断——弹性应力场只有
   Lamé 解的 40%~60%。关闭后回到 90% 以内。
4. **气腔边界环识别容差不能取 0.5**：判据 `d ≤ a₀ + r_p + tol·L₀` 在 `tol = 0.5` 时正好
   落在第二壳层的半径上，浮点比较左右摇摆（同一算例 Python 侧 36 个、C++ 侧 30 个）。
   取 0.4 落在第一、二壳层之间的空档。
5. **能量账本必须包含"接触弹性能"与"重叠保护移出的动能"**：`k_n ≈ 1.87e6 N/m`，10% 重叠
   时单个接触就存 5.9e-4 J，压碎段累积可达 **3.5 J**；刚性回弹是**速度改写**（不是力的做功），
   累计移出 **0.59 J**。两项都补进账本后，残差从 **−18.4% 降到 0.37%**。
   （为此在 `DEMContact` 上新增了 `elastic_energy` 字段，LSD / Hertz-Mindlin 两个接触模型
   都写入，`DEMSolver` 汇总。）
