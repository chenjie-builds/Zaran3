# 惰性巴西圆盘弹性加载测试

本算例使用三角点阵和永久弹性键合表示圆盘，上下两排运动学粒子作为压头，按
相同速度向圆心运动。它验证加载前的弹性响应，不包含断裂和裂纹扩展。

运行方式：

```bash
python generate_case.py
Zaran3.10.2.exe path/to/dem_brazilian_disk_test
python verify.py --sim ./backup --case .
```

验证内容包括：压头位移、圆盘对称性、加载方向收缩、圆心附近横向拉伸以及上下
压头反力平衡。

当前 Debug 结果：85 个圆盘节点、222 条连接，竖向直径变化
`-2.458e-4 m`，圆心横向平均应变 `1.526e-3`，上下压头反力
`+5.20414 N / -5.20414 N`。
